Animation Design — Section by Section

Lenis + GSAP ScrollTrigger. Does this look right before I write the spec?

📦 Libraries (CDN — no install needed)

  • Lenis — smooth scroll inertia, that "expensive momentum" feeling
  • GSAP + ScrollTrigger — all animation logic, free tier

🎬 Hero

  • Background photo parallax — image moves at 60% scroll speed (cinematic depth)
  • On load: "Welcome to" fades up → Salvation logo scales in → Studios + CTA stagger up
  • Mouse parallax on the purple glow orbs (subtle, 20px max movement)
  • Hero content fades out as you scroll away (opacity tied to scroll position)

✍️ Welcome — "A labour of love"

  • Headline words slide up in sequence (100ms stagger)
  • Body paragraphs fade up one by one as they enter viewport
  • Stats (6 rooms, 5yr, 13m) count up from 0 when in view
  • Photo stack: main photo reveals with clip-path wipe, accent photo follows 200ms later

🏠 Rooms

  • Header slides in from left
  • Live Room hero card: image scales from 1.1→1.0 as it enters (feels like it's arriving)
  • Room cards stagger in left-to-right with 80ms delay each
  • Hover: image scale + subtle card lift (already in CSS, enhanced)

🎛️ Neve + In-Room + Services

  • Images: clip-path wipe reveal (curtain pulls back left-to-right)
  • Text blocks: staggered line-by-line fade up
  • In-room photos: parallax scroll (move at 80% speed for depth)

💬 Testimonials

  • Cards fade up with slight Y offset, staggered 100ms apart
  • Quote marks animate in first, then text

🖼️ Gallery

  • Images reveal in a wave — top row first, then bottom row, 60ms stagger per image
  • Subtle scale from 0.95→1.0 on reveal

📅 Booking Band

  • Text and button scale up from 0.97→1.0 with fade — clean, confident

⚡ Global

  • All animations respect prefers-reduced-motion — they simply don't run
  • Lenis disabled on mobile if needed for performance
  • All animation code in a single <script> block at the bottom of the HTML
